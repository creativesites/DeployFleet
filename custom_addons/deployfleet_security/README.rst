====================
DeployFleet Security
====================

Role groups (Driver → Dispatcher → Fleet Manager → Owner, plus HR/Payroll
Officer and System Auditor) and DeployFleet's own product license /
entitlement enforcement.

Not to be confused with per-role *AI* permissions, which live in the
(later-phase) ``deployfleet_ai_permissions`` module — this module is about
who can use the product at all, not what an AI agent may tell them.
