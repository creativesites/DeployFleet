====================
DeployFleet Customer
====================

``deployfleet.contract`` (recurring commercial terms with a customer —
deliberately optional on a shipment, since spot loads have none) and
``deployfleet.depot`` (a named origin/destination point for routes).

This is the layer of DeployGuard's client/site hierarchy that barely
changes shape in the fork — see ``docs/architecture/01-module-audit.md``.
