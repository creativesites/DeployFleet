# DeployFleet

An Odoo-based operations platform for transportation and logistics companies, forked from the DeployGuard security-workforce platform and rebuilt around fleet dispatch, vehicle/workshop management, driver payroll, and freight billing — starting with local trucking companies in Zambia.

This repository currently contains the Phase 1 architecture planning deliverables. No Odoo modules have been implemented yet — implementation begins only after the architecture below is reviewed and agreed.
